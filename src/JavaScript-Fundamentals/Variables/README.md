# Variables

Executable examples covering JavaScript variable declarations.

- [Variable Scoping](./variableScoping.test.js) - `var`, `let`, and `const` scoping rules.

- [Let Declarations](./letDeclarations.test.js) - declaration syntax, evaluation order, and the Temporal Dead Zone (TDZ).

> **TDZ (Temporal Dead Zone):** The period between entering a scope and the variable declaration being evaluated. Accessing a variable in TDZ throws a `ReferenceError`.
